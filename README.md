# Registro de Entradas y Salidas con Código de Barras

Proyecto SENA. Es un sistema que registra entradas y salidas de personas usando un lector de código de barras, y luego imprime un ticket con una impresora térmica Xprinter.

## Integrantes
- Hanna Sanchez
- Nidia Gomez

## Tecnologías
- Deno + Oak (backend)
- Astro (frontend)
- MySQL (base de datos)
- Lector de código de barras
- Impresora térmica Xprinter

## Cómo clonar el proyecto
git clone https://github.com/HannaSan27/proyecto-perifericos.git
cd proyecto-perifericos
git checkout develop
